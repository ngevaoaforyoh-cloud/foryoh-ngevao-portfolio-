# Ngevao Foryoh — Personal Portfolio

A React portfolio website presenting the education, skills, practical experience, community involvement and curriculum vitae of Ngevao Foryoh.

## Requirements
- Node.js and npm

## Run locally
1. Extract the project folder.
2. Open a terminal in the project directory.
3. Run `npm install`.
4. Run `npm start`.
5. Open the local address shown in the terminal (usually `http://localhost:3000`).

## Production build
Run `npm run build` to create an optimized production build in the `build` directory.

## CV
The current two-page CV is stored at `public/Ngevao-Foryoh-CV.pdf` and is displayed on the CV page with a download option.

## Content accuracy
The portfolio content is based on the supplied curriculum vitae. No unverified employment, internships, project deployments, GitHub profile or social-media accounts have been added.
